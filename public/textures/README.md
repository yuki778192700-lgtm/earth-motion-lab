# Earth texture source

`earth-blue-marble-2048.png` is NASA's 2048 × 1024 seamless Blue Marble image.

- Source: https://svs.gsfc.nasa.gov/2915
- Credit: NASA/Goddard Space Flight Center Scientific Visualization Studio
- Dataset: Blue Marble Next Generation, courtesy of Reto Stöckli (NASA/GSFC) and NASA's Earth Observatory
- Projection: equirectangular
